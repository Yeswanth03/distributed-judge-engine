# Frontend

React 19 + Vite + TypeScript. Tailwind with shadcn/ui (Radix, Nova preset), React Router, TanStack Query,
Monaco (bundled, Python only) and react-markdown.

## Run it

The backend runs behind the gateway on http://localhost:8000 (`docker compose up -d --wait` from the repo root).

```bash
npm install
npm run dev
```

The app runs on **http://localhost:5500**. That port is already in the User Service's `OAUTH_ALLOWED_REDIRECTS`,
so Google and GitHub sign-in can return to it. Set `GATEWAY_URL` to use another gateway.

## How it talks to the backend

- Every call goes to `/api/<gateway path>`. The dev proxy (and later the production server) strips `/api` and forwards
  to the gateway, which keeps API paths apart from page URLs such as `/problems/two-sum`.
- The access token is kept in memory only. The refresh token is an HttpOnly cookie the browser sends to
  `/auth/refresh` itself; on page load the app refreshes once to restore the session.
- Live submission status uses the Submission Service's Server-Sent Events, read with `fetch` so the request can carry
  the `Authorization` header (the browser's `EventSource` cannot).
- Run results are polled every second until the judge answers.

## Scripts

| Script              | Does                                              |
| ------------------- | ------------------------------------------------- |
| `npm run dev`       | Dev server with the gateway proxy                 |
| `npm run build`     | Type-check and build to `dist/`                   |
| `npm run typecheck` | TypeScript only                                   |
| `npm run lint`      | oxlint (generated `src/components/ui` is skipped) |
| `npm run format`    | Prettier                                          |

Components under `src/components/ui` are generated by `npx shadcn@latest add <name>`; after adding one, check that its
`cn` import reads `@/lib/utils`.
